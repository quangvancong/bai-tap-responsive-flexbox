CSS Flexbox là gì?

CSS Flexbox là công cụ bố cục giúp sắp xếp các phần tử theo hàng hoặc cột một cách linh hoạt.

Ưu điểm của Flexbox

Flexbox giúp căn chỉnh các phần tử, phân chia không gian và xây dựng giao diện web dễ dàng.

Thiết kế Responsive

Responsive giúp website thích ứng với nhiều kích thước màn hình như máy tính và điện thoại.
